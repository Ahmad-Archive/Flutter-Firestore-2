# Tugas Flutter + Firestore

Project flutter yang memakai database firebase. Dengan menggunakan Firestore.

## Prasyarat
Sebelum menjalankan project ini, pastikan komputer Anda telah menginstal:

- Flutter SDK (Versi terbaru)

- Dart SDK

- Code Editor seperti VS Code atau Android Studio

- Browser Google Chrome (untuk menjalankan versi Web)

- Emulator Android atau HP Android fisik (untuk menjalankan versi Android)

## Proses Instalasi & Menjalankan Project

### 1. Clone Repository
```bash
git clone <url-repo>
cd <nama-repo>
```

### 2. Install Dependencies
```bash
flutter pub get
```

### Jalankan Aplikasi

- Menjalankan di Web
```bash
flutter run -d chrome
```

- Menjalankan di Android (Pastikan emulator sudah aktif atau Terhubung dengan HP)
```bash
flutter run -d android
```
